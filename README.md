# Hub

https://zkaraman25.github.io/

Popis aplikacija. Prijava je zajednička s Aparatima; popis se sprema u repo zkaraman25/aparati, grana `data`, datoteka `hub.json`.

## Stan Škalinova (`/stan/`)

Tlocrt stana A1 s mjerama (klik na prostoriju ili element), probna ploča za svjetla, pogledi i renderi, dokumenti. Ugrađeni dokumenti su u `stan/dok/`, slike u `stan/slike/`. Vlastiti dokumenti (uz prijavu) idu u repo zkaraman25/aparati, grana `data`, mapa `stan/` (popis `stan/index.json`, datoteke `stan/dokumenti/`).
